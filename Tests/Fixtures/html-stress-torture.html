marc HTML torture

Every case below is markup an agent can plausibly emit and a browser accepts, where marc's source parser and the live DOM are likely to disagree. The clean cases live in html-stress-test.html. Keep them apart, so a real regression there is not buried under known divergence here.

What matters in each case is whether the reader still lands on the same blocks the browser does, and whether anything worse than a wrong reading mark happens: a hang, a phantom outline entry, a lost heading, or a graph edge to a file that was never linked. One case is expected to diverge and is marked as such; the rest are here to stay aligned.

Each case is measured on its own, so one case going wrong does not decide the verdict on the next. A count that differs means a reading mark would land on the wrong element; a count that matches with different text means the mark lands on the right element but its identity was taken from something nobody can see.

1. Tags the browser closes for you

2. Things that look like tags and are not

2.1 Markup inside a comment

A comment sitting between blocks, as above, is easy to get away with: a scanner that stops at the first > ends the comment inside the commented-out tag, but the leftovers land between blocks where there is nothing to attach them to.

A comment holding markup and sitting inside a block is the one that bites. Stopping at the first > ends the comment inside the commented-out tag, and the rest of it lands in the block that is open. This paragraph's text, and therefore its identity, would then be taken partly from something nobody can see, and editing only the comment would mark the paragraph as revised. 7. The report

Each case is measured on its own: the blocks the DOM walker finds inside it, against the blocks the source parser finds in the same markup parsed alone, by count and by text. A case whose counts differ is one where a reading mark lands on the wrong element. A case with the same count and different text is one where the mark lands on the right element but its identity was taken from something the reader cannot see, so the block reads as edited when nothing visible changed. Measuring each case alone is what keeps the verdicts independent, since in the whole file every divergence shifts everything below it.
